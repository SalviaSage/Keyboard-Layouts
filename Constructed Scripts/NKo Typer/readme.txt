NKo Typer;
https://en.wikipedia.org/wiki/N%27Ko_script

This is a constructed script that has some similarities with the Arabic script.
It is intended to write some African languages.
Its direction is right to left, the same as Arabic.

Similar to Arabic, the alphabet features a low line running across the words and the letters are joined together.
To type an empty connector line, like the Arabic tatweel character, type shift + ctrl + space key on the keyboard.

Similar to the Arabic mark sukūn, the mark "dagbasinna" (ߑ) can be typed by pressing ctrl + space.

There is no letter (q), therefore, I put NKo punctuation marks at that position (߸), and with shift (߹).

There is a full row of combining diacritics on the top row from 1 to 0.

By default, the numbers are typed from the numpad as ߀߁߂߃߄߅߆߇߈߉.
Press the right alt key + number ket to type as 0123456789.

To type the currency sign for the currency "taman";
Press ctrl + shift t. For example; ߿߁߀߀߀ = ŧ1000
This particular currency sign is transliterated as (ŧ) in the Latin alphabet.

To type the currency sign for the currency "dorome";
Press ctrl + shift + d. For example; ߾߁߀߀߀ = đ1000
This particular currency sign is transliterated as (đ) in the Latin alphabet.

	Section on NKo numerals:
NKo numerals use positional notation.
Unlike both Western and Eastern Arabic numerals, digits decrease in significance from right to left.
That is, the direction of the digits is also correctly right to left.
This is in contrast with Arabic and other systems.
So for example, after 9, it becomes 01 instead of 10.

https://www.afrikanistik-aegyptologie-online.de/archiv/2012/3553
"A curious feature of numeric notation in right-to-left scripts is that the order of digits is almost always the same as in left-to-right running scripts, i.e., the least-significant digits are placed to the right. The only known exception is found in the Nko alphabet, where the direction of writing is also transferred onto the direction of number representation, with the least significant digit placed to the left, thus the highest one is written first:"
