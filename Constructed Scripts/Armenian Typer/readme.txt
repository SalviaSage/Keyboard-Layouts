Armenian Typer;
This keyboard layout lets you type the Armenian Alphabet.
I tried to keep the letters in alignment with where the letters are on the QWERTY layout.
However, the letter (q) was not there, so I assigned it to another letter (ղ).

Using the caps lock button is the only way to type capital letters.
Pressing shift gives us extra and variant letters.
These letters are supposed to relate to the base letters.
For some, there are no alternative letters, in which case, pressing shift + key gives nothing.

Top row number key houses additional letters.
For some letters, there are shift variants of the letters.
These are phonetically related to the base letters.

The Armenian currency sign, the Dram sign, can be typed by pressing AltGr + D.

You can type certain Armenian punctuation marks by pressing the AltGr + punctuation mark key.

Recommended font for Armenian on Windows: Cambria
